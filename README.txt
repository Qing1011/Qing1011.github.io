# GitHub Pages (Option A) quick start

1. Create a **public** repo named `YOURUSERNAME.github.io`.
2. Upload `index.html` and `.nojekyll` (both in this zip).
3. Visit `https://YOURUSERNAME.github.io`.

## Customize
- In `index.html`, update the email user/host in the small JS block.
- Replace the Google Scholar/DBLP links with your profiles.
- If you add `/papers/` or `cv.pdf`, upload those files/folders to the repo root.
